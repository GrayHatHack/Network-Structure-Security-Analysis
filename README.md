# Network Structure & Security Analysis

## 📌 Objective
To analyze network topologies, understand architecture layouts, and evaluate network security controls to protect data in transit and identify potential entry points for security threats.

---

## 🛠️ Tools & Technologies Used
* **Concepts:** Network Topologies, Firewalls, IP Addressing, Subnetting, OSI Model
* **Analysis Focus:** Identifying exposed ports, access points, and traffic routing vulnerabilities.

---

## 📋 Key Areas Covered
1. **Network Mapping:**
   * Reviewing how devices (routers, switches, workstations) are interconnected within a structure.
2. **Security Controls Evaluation:**
   * Assessing the role of firewalls and network segmentation in preventing unauthorized lateral movement.

---

## 🚀 Key Takeaway
Learned how a well-structured and segmented network architecture is critical for containing breaches and minimizing attack surfaces in an organization.
